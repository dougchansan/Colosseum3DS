# Interior/TV renderer verification

`verification.json` records the original-asset nine-model shop probe and the source-only colored-corner target probe. Source files are reproducible through `tools/sandbox/scene_probe.mk`; private disc-derived packs and captured game images are intentionally not checked in. See [the preparation and format documentation](../../outskirt-interior-assets.md).

The original-asset run reached at least 76 submitted frames and then hit its configured 55-second wall limit. It rendered the original reporter model into the shop television, with the original room camera sampled at 4 seconds. This probe executes no story script and proves no dialogue, battle, save, later-area or physical-console completion.
